## قواعد به‌روزرسانی

1. تغییر ظاهر/توکن/کامپوننت → فقط `design-system.md`.
2. تغییر ساختار پوشه، مرز سرور/کلاینت، بودجه یا گیت → فقط `frontend-architecture.md`.
3. تصمیم معماری بک‌اند یا دامنه‌ی محصول → فقط `architecture.md`.
4. بدهی جدید → `tech-debt.md` (با شاهد و اقدام)؛ نه در اسناد دیگر.
5. گزارش‌های موقت (بازنگری، برنامه‌ی مهاجرت، یادداشت جلسه) **سند دائمی نیستند**: نتیجه‌ی تصمیم به سند مرجع منتقل و خود گزارش حذف می‌شود.

## گاردهای خودکار مرتبط

```powershell
pnpm check:design --strict   # پالت/توکن/حرکت/z-index
pnpm check:contrast          # AA؛ ۵ base × ۴ برند × ۲ تم + tone
pnpm check:size --strict     # بودجه‌ی اندازه‌ی فایل
pnpm check:boundaries        # مرز پکیج‌ها
pnpm check:all               # همه با هم
```
